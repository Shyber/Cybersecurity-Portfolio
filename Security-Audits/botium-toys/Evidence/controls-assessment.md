# Controls Assessment

## Objective

Assess the security controls currently implemented by Botium Toys
and identify controls that are missing or require improvement.

| Control | Status | Evidence / Observation |
|---|---|---|
| Least Privilege | No | Employees have access to internally stored data, including potentially sensitive information. |
| Disaster Recovery Plans | No | No disaster recovery plans are currently in place. |
| Password Policies | Yes | A password policy exists, but its requirements are insufficient. |
| Separation of Duties | No | Separation of duties has not been implemented. |
| Firewall | Yes | A firewall is implemented with defined security rules. |
| Intrusion Detection System | No | No IDS has been installed. |
| Backups | No | Critical data is not currently backed up. |
| Antivirus Software | Yes | Antivirus software is installed and regularly monitored. |
| Legacy System Monitoring | Yes — Needs Improvement | Legacy systems are monitored and maintained, but there is no regular schedule and intervention procedures are unclear. |
| Encryption | No | Encryption is not currently used to protect customer credit card information. |
| Password Management System | No | No centralized password management system is implemented. |
| Physical Locks | Yes | The physical location has sufficient locks. |
| CCTV | Yes | Up-to-date CCTV surveillance is in place. |
| Fire Detection/Prevention | Yes | Fire detection and prevention systems are functioning. |

## Key Observations

The assessment identified significant gaps in access control, data
protection, backup, disaster recovery, and monitoring capabilities.

The organization does have several foundational controls in place,
including a firewall, antivirus software, physical security, CCTV,
and fire detection systems.
